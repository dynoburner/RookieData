# 🏈 Dynasty Data Journal (199X Retro Edition)

A retro 80s/90s pastel vaporwave dashboard designed for fantasy football dynasty managers to view prospect scores, Big Boards, rankings, and Year 1, 2, and 3 Points Per Game (PPG) projections.

## Features
- **Retro CRT Aesthetic:** Custom scanlines, glowing header marquees, and monospace typography (`VT323` and `Press Start 2P`).
- **Pastel Conditional Formatting:** Excel-inspired soft pastel highlighting for elite prospects, tiers, and scoring thresholds.
- **Interactive Navigation:** Seamlessly switch between Big Boards, WR/RB Rankings, Multi-Year Projections, and Comparison Matrices.
- **Instant Search & Filtering:** Filter prospects by position (QB, RB, WR, TE) or search by player name.

## How to Publish on GitHub Pages
1. Create a new repository on GitHub (e.g., `dynasty-journal`).
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the main branch.
3. Go to your repository **Settings** -> **Pages**.
4. Under **Build and deployment**, set the source to **Deploy from a branch** (`main` / root).
5. Click Save! Your live dynasty journal URL will appear in a few moments.
